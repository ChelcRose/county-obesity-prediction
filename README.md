# County-Level Adult Obesity Prevalence Prediction

Thesis implementation for predicting county-level adult obesity prevalence using food environment, socioeconomic, demographic, and health indicators through stacking ensemble learning.

## Models

- Linear Regression
- Random Forest Regressor
- XGBoost Regressor
- Stacking Ensemble with Linear Regression meta-learner
